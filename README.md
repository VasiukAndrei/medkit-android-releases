# Домашняя Аптечка для Android

Скачать подписанный APK для Android 9 и новее можно на странице [последнего релиза](https://github.com/VasiukAndrei/medkit-android-releases/releases/latest).

Откройте `medkit.apk` на телефоне и подтвердите установку. Если Android запросит разрешение на установку из этого источника, выдайте его в системных настройках.

Файл `update.json` содержит версию сборки, ссылку на APK и его контрольную сумму SHA-256.
